## Core claim being recorded

```text
A = A(x)
```

with local spherical weak-field form:

```text
A(r) = Rs/r = 2GM/(c^2 r)
```

```text
<A_path>(z)       = (b/L + 0.35z) / (1 + 0.15z)
A_path,local(z)  = (b/L + 0.70z) / (1 + 0.30z)
```
