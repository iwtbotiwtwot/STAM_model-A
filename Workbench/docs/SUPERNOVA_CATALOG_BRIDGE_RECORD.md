# Supernova catalog bridge and discrepancy record

## Purpose

This document preserves the adjustment/bridge work while allowing Model-A to move forward with no-`b` tests.

The main empirical issue is not simply whether STAM can fit current supernova distances. STAM's central cosmological claim is that current inferred distances may mix true geometry with path accumulation and catalog inference.

## Current working summary

The supernova tests found:

```text
Pantheon/Union3 behave like one reference family.

DES behaves differently from Pantheon/Union3.

STAM's locked-b residual against DES is similar in size and structure to DES's independent empirical discrepancy from Pantheon/Union3.

Small b adjustments do not bring Pantheon, Union3, and DES into real agreement.
```

Therefore, DES should not be fit away by choosing a DES-specific `b` unless an independent DES-specific catalog/systematics explanation is specified first.

## How to phrase the result

Preferred wording:

```text
The b-like term measures the gap between current catalog-inferred distance and the no-b STAM accumulation-distance law.

Pantheon/Union3 show one bridge behavior. DES shows a different bridge behavior, but the DES difference is also visible as an independent catalog discrepancy.
```

Avoid wording:

```text
STAM needs b to fit supernovae.
```

Avoid wording:

```text
DES proves STAM wrong.
```

The current evidence is more subtle:

```text
DES is already discrepant from the Pantheon/Union3 reference family,
and STAM inherits a similar discrepancy when tested against DES.
```
