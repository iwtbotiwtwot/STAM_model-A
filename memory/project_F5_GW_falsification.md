**F5 finding (2026-05-07):** Bold STAM in Framework C, with the simplest scalar generalization (A as only field, metric constructed from A alone), is **observationally falsified** by LIGO/Virgo/KAGRA gravitational wave polarization measurements.

**The math:**
- Bold STAM Framework C predicts 100% scalar/longitudinal GW power, 0% transverse-tensor.
- LIGO requires ≥50% tensor and ≤10% non-tensor for consistency with observed compact binary mergers.
- Pure scalar gravity (Nordstrom and successors) is in the same class and was historically ruled out for the same reason.

**What survives F5 unchanged:**
All local results — Hawking thermodynamics (Q8-Q12), strong-field structure (SF3-SF5), F1 (Penrose evasion), F2 (EP), F3 (Birkhoff via Framework C). These don't depend on GW polarization structure. The bubble picture, no-crossing, no-interior, bubble-as-2D-membrane, holographic-area-entropy are all conceptually intact.

**What needs to change:**
Framework C as specified in SF6 — where A is the only dynamical field and the metric is constructed from A alone — is incomplete. Bold STAM needs amendment to **scalar-tensor structure** (Option I in F5 script):

- Promote the metric to an independent dynamical field with its own tensor degrees of freedom (giving h_+, h_×).
- Couple A to the metric through the bold-STAM construction rule, as one field among others.
- The scalar A still produces local effects (Hawking, no-crossing, A=1 boundary).
- GW polarization comes mostly from the tensor metric, like in Brans-Dicke.

This amendment is well-understood theoretically (scalar-tensor gravity is a developed research area) but hasn't been written down for bold STAM specifically. Doing so is comparable in scope to writing Q8-Q12 or SF3-SF5.

**How to apply:**
- When discussing bold STAM going forward, do not claim Framework C in the SF6 form is a complete theory of gravity. It is incomplete.
- Bold STAM as a conceptual / phenomenological framework remains intact — local predictions, no-crossing, bubble picture are unaffected.
- The scalar-tensor amendment is the next major theoretical step. Until it's done, the framework's GW predictions are not consistent with observation.
- Don't overclaim "bold STAM is consistent with all current observations" — F5 specifically refutes this for current Framework C. Honest characterization: "bold STAM with current scalar-only specification is inconsistent with LIGO; the scalar-tensor amendment is open theoretical work that should restore consistency."

**Why this is honest progress, not a refutation:**
F5 is exactly the kind of result running fatalities is supposed to produce — a real, identifiable, addressable gap. Not "your framework is wrong" but "your framework is incomplete in this specific way." The bubble picture and the local results don't depend on the failed piece. The fix is known. This is a research item, not a death blow.
