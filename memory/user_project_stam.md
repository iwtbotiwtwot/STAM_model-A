The user is Sean Brady (or works closely with him), author of STAM Model-A. The project is a research scaffold for a proposed theoretical framework, not established physics — the README is careful to label every claim by maturity (algebraic identity, numerically checked, catalog diagnostic, exploratory, open).

The framework is built around one dimensionless field `A(x)`, with `A(r) = Rs/r = 2GM/(c^2 r)` in the spherical weak-field form. Different observables are interpreted as projections: `grad(A)` → gravity, `∫ A ds` → propagation delay, `A=1` → horizon, `A = v^2/c^2` → escape condition.

Maturity at time of writing (2026-05): weak-field gravity / GPS-style clocks / Shapiro / mass-estimator identities are numerically checked. Cosmological distance comparisons against Pantheon/Union3/DES are catalog diagnostics with a "no-b" preferred form and a historical bridge term `b ≈ 354.95` retained for comparison. Galaxy rotation, strong-field beyond `A=1`, GW propagation, and a quantum resolved/unresolved interpretation are exploratory.

Style preference visible in the README and scripts: explicit status labels, separation of supportive demos from falsification tests, locked-parameter requirement before prediction tests, no over-claiming.
