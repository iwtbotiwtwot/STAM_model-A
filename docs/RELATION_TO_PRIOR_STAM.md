# Relation to Prior STAM Notes

The archived 2 May 2026 PDF frames STAM as a dimensionless scalar accumulation-field model with:

```text
A(r)=Rs/r
local gravity from grad(A)
propagation delay from int A ds
A=1 as a horizon-like threshold
cosmological distance excess from path accumulation
```

This repository continues that variable-field Model-A direction.

## What changed from the abandoned constant-A scaffold

The constant-`A0` idea is not used as the core model here.

A globally constant `A` would imply:

```text
grad(A)=0
```

and therefore would not recover local gravity through:

```text
g = (c^2/2)grad(A)
```

STAM_model-A instead keeps `A` variable:

```text
A = A(x)
```

with local spherical weak-field limit:

```text
A(r)=2GM/(c^2 r)
```

and cosmological path functions:

```text
<A_path>(z)
A_path,local(z)
```

The key future task is to show whether these local and cosmological forms are connected by a deeper field equation.
